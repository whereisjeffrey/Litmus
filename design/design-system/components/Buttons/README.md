Buttons come in exactly three weights; cobalt is the only color they wear.

- **Primary** — `cobalt` pill, white text, eye icon: reserved for *Show me*, the product's hero verb. One per card, maximum.
- **Secondary** — white pill, 1.5px `line` border, `ink-soft` text. Carries a lock icon when the content behind it is Pro (*Why it survived*).
- **CTA** — `chartreuse` pill with `ink` text, 700 weight: only on dark grounds (the Pro block). Never place chartreuse buttons on white.
- All: `radius-pill`, `button` type, padding 8px × 14px, icons are inline stroke SVG in the text color.

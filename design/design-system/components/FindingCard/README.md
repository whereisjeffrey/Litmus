The finding card is the atom of the drawer: one qualitative finding, fully stated, with its evidence attached.

Anatomy, top to bottom: impact chip + review badge (header row) → headline (`card-headline`, Baloo 2) → narrative (`body-small`, `ink-soft`, 2–4 lines) → evidence block (expanded cards only) → citation chip (only when a knowledge-base lookup backs it — never free-recalled statistics) → action row (primary *Show me* + secondary).

- Ground: `surface` with 1.5px `ink` outline + `shadow-card` on white; outline drops and `shadow-card-band` applies on color bands.
- `radius-card`, `card-pad` (14px). One finding, one card — a card that needs two columns is two cards.
- Collapsed findings use FindingRow instead; expand the top 2–3 by impact.

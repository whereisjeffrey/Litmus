The finding row is the collapsed finding — the density tool for pages with many findings.

- Row anatomy: impact chip → headline (`card-headline` at 15px, up to 2 lines) → chevron. Tapping expands into a full FindingCard in place.
- Same surface rules as FindingCard (`radius-card`, outline on white, shadow on bands) but `card-pad` shrinks to 12px.
- Use when a page has more than 3 findings: expand the top 2–3 by impact, collapse the rest. Every finding stays visible and readable — collapsing is compression, never concealment.
- Rows are grouped by impact order (HIGH first), not by category.

The review badge is the free tier's proof of rigor: a shield marking that an adversarial reviewer tried to kill this finding and failed.

- Shield icon (inline stroke SVG) + "survived review" in `chip` type, `ink-soft`.
- Two forms: bare (inside a finding card's header row) and outlined (`line` 1.5px border, `radius-pill`) when it stands alone in the teaser row.
- It appears only on findings that actually passed Stage D review — it is a claim, never decoration.
- The full steelman reasoning behind the badge is Pro ("Why it survived"); the badge itself is always free.

Impact chips grade a finding's severity — the only ALL-CAPS element in the system, because severity earns formality.

- Three fixed levels: HIGH (`impact-high` / `impact-high-ink`), MEDIUM (`impact-medium` / `impact-medium-ink`), LOW (`impact-low` / `impact-low-ink`).
- Tint grounds with matching dark inks — rust, not alarm-red: we inform, we don't scold.
- Type: `chip` sizing at 10px, weight 700, letter-spacing 0.04em, `radius-pill`, padding 3px × 9px.
- Never invent a fourth level; never use these colors for anything but severity.
